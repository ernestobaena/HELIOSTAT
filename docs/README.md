# HELIOSTAT Hardware & Test Documentation

This directory contains the collateral needed to build, wire, and validate the heliostat platform.

## Contents

- `wiring_overview.md` – complete schematic narrative plus connection tables.
- `mechanical_drawings.md` – fabrication drawings and dimensional references for mirror and mount structures.
- `assembly_guide.md` – step-by-step build instructions, calibration steps, and setup workflows.
- `BOM.csv` – bill of materials with preferred and alternate components.
- `testing/` – bench and field test checklists along with data capture templates.

All drawings are provided in DXF-style coordinate tables that can be imported into CAD or reproduced on paper. Photographs referenced in the assembly guide are placeholders; replace them with actual build photos during the first article build.
